# VoltraFront

رابط کاربری فروشگاه اینترنتی **Voltra** که با استفاده از Next.js، React و TypeScript توسعه داده شده است. این پروژه با هدف پیاده‌سازی یک رابط کاربری ساختاریافته و قابل توسعه برای فروشگاه اینترنتی و پنل مدیریت محصولات طراحی شده است.

## تکنولوژی‌ها

- Next.js
- React و TypeScript
- Tailwind CSS و shadcn/ui
- TanStack Query و TanStack Table
- React Hook Form و Zod
- Axios

## اجرا

```bash
npm install
```

```bash
npm run dev
```

برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.
